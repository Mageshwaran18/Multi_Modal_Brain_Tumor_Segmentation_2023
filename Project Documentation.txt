Data Preprocessing :- 

Step 1 :- 

The datasets are in the file format of .nii ( NIFTI ) 

.nii (NIfTI) is a file format for storing medical images like MRI or CT scans. It contains:

3D image data (like brain scans)

Info about image size, spacing, orientation

At first thise 3D images are need to be normalized and the normalization can be done using the MinMaxScaller() but it only accepts the 2d data and not 3d. 

Hence at first 3d images are converted into 2d images , and then normalized. After normalization the scalled images are restored back into the same 3d shapes 

Step 2:- 

As we have 4 types of modalities and we have also noticed that the information we can get from T1 ( modality ) can also get from the T1CE modality with additional information too. So to increase the computational efficiency , we are not going to use T1 for the training purposes. 

The process of normalization is done on all the three modalities ( FLAIR , T1CE , T2 ) and the were combined into a single numpy file . By stacking on the another.

Step 3:- 

When we are looking into each images , most of the areas are black ( which are not part of the brain ) . So these area may affect the model training and it's accuracy. Hence we are going to crop the images into some extent such that black ( vast areas ) are removed. 

And we are using the data / images , which contains atleast 1% of valid image information comparing with the entire image.

Summary : -

Model Training , Loss Function , Optimizer Setup :- 


[ As we are training the model in the Kaggle environment , we may face a challenge where during the training we may not get a correct corresponding mask for a respective input image hence , we built a load_aligned_data , which will help us to get the image and it's repective mask crtly ]


Categorical Focal Loss -> Focuses more on the hard to classify area. Add more contribution toward the loss of hard ( features ) misclassified samples then the loss of easy ( features ) misclassified samples. Which is controlled by the ' y ' parameter.

Dice Loss -> loss function commonly used in the image segmentation process. Measure the similarity between the predicted segmentation and the groud truth.It's use full for the imbalanced data where the foreground is much smaller then the background.
Foreground: Area with the object of interest (e.g., tumor).
Background: Everything else (non-tumor).

IOU :- Used in the accuracy of object detection or image semgmentation process.It measures the overlap between the predicted region and the ground truth region. Higher the value , higher the accuracy 

Adam Optimizer :- Combination of two optimizers ( momentum + RMSprop ) to acheive fast convergence and robust performance. Moving average of the gradient and Moving average fo the squared gradient. 

Example: For a brain tumor image:

Dice Loss ensures good overlap between predicted and actual tumor regions

Focal Loss helps identify small tumor regions

IOU Score of 0.8 would mean 80% overlap between prediction and ground truth

Adam optimizer adjusts learning rates automatically for better convergence.
